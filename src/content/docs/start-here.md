## Read the labels

- **Source-backed:** confirmed in an inspected repository file; this does not imply successful execution.
- **Needs verification:** implementation or behavior still requires inspection or runtime testing.
- **Planning:** proposed design or a decision awaiting confirmation.

## Something broke?

Record the project, branch or commit, exact command, error output, platform, and what you expected. Remove secrets before sharing logs. Open an issue in the relevant project repository.
