**Everything below is proposed, not implemented.**

## Product brief to decide

- Primary writer workflow: drafting, planning, revision, or all three?
- Supported platforms: browser, desktop, mobile?
- Local ownership and offline requirements.
- Manuscript organization: book, part, chapter and scene.
- Canon reference: characters, locations, timelines and continuity notes.
- Import and export formats, with formatting preservation requirements.
- Whether AI belongs in the first version; provider choice and explicit user control.

## Candidate first milestone

Create a project, draft a chapter, save reliably, reopen it, and export usable text. Validate this loop before expanding the feature list.

## Acceptance checklist for the first real build

- Draft text survives reload and restart.
- Save state and failure messages are visible.
- Export produces readable output.
- Backup and recovery are documented and tested.

## Decisions still open

Technology stack, storage format, authentication, sync, licensing, accessibility targets, and release scope.
